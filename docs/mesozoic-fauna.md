# 中生代の陸の広域動物群

化石産地の外でも動物を観察できるように、広域動物群12項目を既存の生きもの一覧の末尾に追加した。既存の種の番号・宿題の対象を維持し、保存データ内の現象の記録は既存の版3の読み込みで移動する。

これらは単一種を世界中に配置したものではない。時代・地域ごとに入れ替わる近縁の動物をまとめ、共通の代表像で観察するゲーム用の項目である。図鑑の3言語の説明にもこの区別を表示する。年代は群の観察可能期間の概略で、全期間に同一の姿の動物がいたことを意味しない。陸と干潟を対象にし、海には配置しない。

図鑑画像と透過スプライトは既存の復元画像を複製して利用し、新たに制作した種固有の復元図としては扱わない。元画像と対象群は各画像フォルダのmanifest.jsonに記録した。描画上の体長は追加項目ごとの代表値を使う。

エオラプトル、ヘレラサウルス、アルゼンチノサウルス、ギガノトサウルスは既存の化石産地の指定を残し、南アメリカ大陸も生息範囲に加えた。生存期間は変更していない。産地で出会いやすくなる既存の仕組みも維持する。

参考にした概説：

- [Australian Museum: The Mesozoic era](https://australian.museum/learn/dinosaurs/mesozoic-era/) — 中生代の陸上動物群とゴンドワナのつながり。
- [NPS: Evolution on Land](https://home.nps.gov/subjects/fossils/evolution-on-land.htm) — 恐竜に加え、両生類・カメ・ワニの親戚・キノドン類などを含む陸上生態系。
- [Utah Geological Survey: Dinosaurs & Fossils](https://geology.utah.gov/popular/dinosaurs-fossils/) — 昆虫・哺乳類・恐竜などを含む中生代の多様な動物。

検証では中生代の各期の開始・中間・終了の時点について、緯度−85〜85度・経度−180〜175度を5度刻みで調べ、全陸地点に4群以上の動物がいることを確認する。植物・生痕・微生物は動物数に含めない。この検査は格子点での分布を確認するもので、地図上の連続したすべての地点の実測ではない。
