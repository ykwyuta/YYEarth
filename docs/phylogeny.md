# 系統樹マップ

図鑑一覧の「系統樹マップ」から、上から下へ枝が広がる連続マップを開きます。背景にカンブリア紀から第四紀までの12の帯を重ね、時代をまたいで代表的な生物の近縁関係を比較できます。カードから図鑑の詳細・探索レーダーへ進めます。「系統樹へ」または Esc で同じ表示位置・拡大率に戻ります。図鑑詳細の「系統樹で見る」は、対応する生きものを中心に拡大し、祖先側の経路を金色で示します。

ドラッグ・1本指のスワイプ・矢印キー・WASDで上下左右へ移動し、ホイール・2本指のピンチ・＋／−で拡大縮小します。ピンチは2本の指の中心、ホイールはカーソルの位置を保って拡大します。右上のミニマップには全景と現在の表示範囲を示し、クリック・タップ・ドラッグした位置へ移動できます。「全体を見る」・Home・0で全景に戻ります。縮小時は枝とカードの位置、拡大すると名前と復元画像が見えます。未撮影の画像は薄く表示します。図鑑の収録や撮影評価は撮影したときだけ増えます。日本語・英語・中国語、ブラウザ版・Windows版で共通です。ブラウザ版ではカード上からなぞっても移動でき、2本指の後に残った指がカードを開くことはありません。

## データと読み方

`src/phylogeny.rs` に32の枝と代表種の slug、マップ配置・カメラを定義し、`src/game/tree.rs` で描画と操作を実装します。既存の `SPECIES` の名前、画像、図鑑番号、生存年代、収録状態を使い、別の生物データを複製しません。全代表種を一度に配置し、同じ仲間で年代の重なるカードは別の列に並べます。

背景の紀はすべて同じ高さにし、各帯の内側ではカタログの年代を線形に配置します。全体を通した年代軸は等間隔ではありません。カードは生存年代の中間に置き、細い縦線でカタログ上の生存範囲を示します。カンブリア紀より前の上部は年代の付かない模式的な分岐の領域です。

枝分かれの位置は代表種や子の枝より上になるように配置した模式図であり、分岐年代を推定したものではありません。枝の終端は絶滅時期を意味しません。種のカードは仲間の枝に付けた代表例であり、隣の種や後の時代の種の直接の祖先という意味ではありません。陸上植物と動物を真核生物の抜粋として扱い、細菌・古細菌・菌類など生命全体を網羅しません。中間の分類群を省略し、一部の枝は複数の分岐をまとめています。

鳥類は獣脚類・恐竜の内側、翼竜は恐竜の外側、哺乳類は羊膜類の単弓類側に配置します。アノマロカリスなどは「節足動物と幹系統」、メガゾストロドンなどは「哺乳類と近縁群」に含め、現生群の厳密な冠群と取り違えない名称にしています。ティクターリクは肉鰭類の枝に置き、四肢動物の直接の祖先とは断定しません。分類の不確かな生物・生痕は代表例に選んでいません。
