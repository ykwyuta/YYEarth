# 系統樹マップ

図鑑一覧の「系統樹マップ」から開きます。カンブリア紀から第四紀までの12タブを切り替え、代表的な生物の近縁関係を比較できます。カードから図鑑の詳細・探索レーダーへ進めます。「系統樹へ」または Esc で系統樹の同じスクロール位置に戻ります。代表種の図鑑詳細にある「系統樹で見る」は、その紀と枝を開いて祖先側の経路を金色で示します。

ホイール・上下キー・Page Up / Page Down・タッチの上下スワイプでスクロール、左右キーで紀を切り替えます。未撮影の代表種も名前を表示し、画像は薄く表示します。図鑑の収録や撮影評価は撮影したときだけ増えます。日本語・英語・中国語、ブラウザ版・Windows版で共通です。

## データと読み方

`src/phylogeny.rs` に32の枝と代表種の slug を定義しています。既存の `SPECIES` の名前、画像、図鑑番号、生存年代、収録状態を使い、別の生物データを複製しません。選んだ紀と生存年代が正の長さで重なる代表種を表示し、その種を含む枝から根までを抜粋します。境界に触れるだけの年代は重なりとしません。代表例のない枝を省くことは、その時代に仲間全体が存在しなかったという意味ではありません。

これは近縁関係を学ぶための簡略化した分岐図です。線の長さ・上下の位置は年代や進化の程度を表しません。種のカードは枝に属する代表例であり、隣の種や後の時代の種の直接の祖先という意味ではありません。陸上植物と動物を真核生物の抜粋として扱い、細菌・古細菌・菌類など生命全体を網羅しません。中間の分類群を省略し、一部の枝は複数の分岐をまとめています。

鳥類は獣脚類・恐竜の内側、翼竜は恐竜の外側、哺乳類は羊膜類の単弓類側に配置します。アノマロカリスなどは「節足動物と幹系統」、メガゾストロドンなどは「哺乳類と近縁群」に含め、現生群の厳密な冠群と取り違えない名称にしています。ティクターリクは肉鰭類の枝に置き、四肢動物の直接の祖先とは断定しません。分類の不確かな生物・生痕は代表例に選んでいません。
