# 古第三紀の豪州・南極の補強

108項目版で手薄だった南方の古第三紀に24項目を追加しました。新生代は132項目、ゲーム全体は生きもの427項目・現象22項目、図鑑449項目です。既存の記録の番号を維持するため、追加項目はID 403〜426へ並べています。

ナンヨウスギ科には南米も分布先として含みます。科・群の項目は単一の種ではなく、地域と年代によって交代する複数の近縁種の代表像です。観察窓はゲーム用の概略で、厳密な初出・絶滅年代や同時共存を保証するものではありません。歯や椎骨などの断片で知られる動物は、全身の復元や体長に推定を含みます。

マルゴン、エタダナ、セイモア島の森、クロス・ヴァレーの沿岸を観察地点に追加。図鑑のレーダーと「行く」で対象の年代と環境へ移動できます。川・湖は専用の地形がないため、既存の水辺環境へ簡略化しています。

## 空白への対応

単一の代表年では、約5460万年前のマルゴンや約2500万年前の動物を見落とします。集計には従来の代表時点に加え、各世全体で観察窓が重なる項目数を追加しました。[収録バランス](cenozoic-balance.md)では植物と動物の数も区別しています。

暁新世の豪州や漸新世の南極など、名前を付けられる陸上動物の化石記録が乏しい区間は、確認できる森林の植物で生態系を補いました。既存の広域グループを「固有種」に数え直したり、マルゴンの動物を暁新世から漸新世まで延長したりしていません。

南極では氷床形成後にもマキ科やナンキョクブナの仲間が残った記録があります。そのため3400万〜1400万年前の氷を一律に南緯55度以南とする描画を改め、ゲーム上の沿岸避難地を設けました。南緯72度以南を氷とし、その外側の陸だけで追加の森林植物を観察できます。この緯度線は簡略化した地形上の表示ルールで、当時の実際の氷床境界を復元したものではありません。1400万年前より新しい時代の表示と、更新世の北半球の氷は従来のままです。

## 検証

地域植物が暁新世・始新世・漸新世の豪州と南極で実際に見つかること、漸新世の森林植物が氷の上には出ないこと、マルゴンの動物が5000万年前や6300万年前へ延長されないことを検証します。既存の撮影テストは追加24項目も訪問・撮影・保存し、描画範囲の検査はカエル・ヘビ・スッポン・シダの描画も対象にしています。
