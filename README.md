# 地球史図鑑 — 時をめぐる観察カプセル（YYEarth）

西暦2650年。あなたは時間旅行学校の生徒です。今学期の宿題は「地球史図鑑」づくり。
時空観察カプセルに乗って過去の地球へ行き、海の中や陸のさまざまな場所で生きものを撮影し、図鑑に収録します。

**第1〜6巻：古生代**（カンブリア紀・オルドビス紀・シルル紀・デボン紀・石炭紀・ペルム紀、5億3880万〜2億5190万年前）を収録。中生代から現代までは今後追加予定です。

> 古生代の図鑑112項目（生物・生痕99、現象13）、観察用スプライト99項目、時代別遠景16枚の画像が揃っています。画像の対応一覧と生成プロンプトは [docs/asset-requests.md](docs/asset-requests.md) にあります。

[YYMongolia](https://github.com/ykwyuta/yyMongolia) の描画・入力・記録の層（Rust → WebAssembly の WebGL2 / Canvas2D、Windows 版の Direct3D11 / Direct2D、IndexedDB と %APPDATA% の記録、タッチ操作、日本語・英語・中国語）を使い、ゲーム本体を作り直しました。復元画像のJPEG・PNGデコードには `image` クレートを使用します。

## 遊ぶ・ビルドする

```
bash build.sh                      # Rust が無ければ rustup で導入し、dist/ に静的サイトを出力
cd dist && python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開く（WebGL2 が必要）。`?lang=en` / `?lang=zh` で表示言語、`?touch=1` でタッチ向けの画面を試せます。

Windows 版：`cargo run --release --bin yyearth-win`（記録は `%APPDATA%\yyearth\saves`）。

Windowsでブラウザ版をローカル確認するときは `python tools/serve.py` で `http://localhost:8765/` を開けます（`dist/` を配信し、JavaScriptとWasmのMIME型も設定します）。

Cloudflare への公開は YYMongolia と同じ（`bash build.sh && npx wrangler deploy`、または Pages でビルドコマンド `npm run build`・出力 `dist`）。

## ゲームの流れ

1. **地図（上空）**：古生代の地球を正距円筒図法で表示。クリック（タップ）した場所へカプセルが飛ぶ。シルル紀からは陸に緑が広がり、氷河時代には南極に氷が現れる。
2. **時間旅行**：画面下の年表で時代を選ぶ。上の細い帯が古生代の6つの紀（クリックでその紀へ）、下の帯がいまの紀の期（全42）。大陸はキーフレームの間を動き、ぶつかると一緒に動いて、ユーラメリカ大陸、やがて超大陸パンゲアになる。「三葉虫の登場」「オルドビス紀末の大絶滅」「最初の森」「ひれから足へ」「石炭紀の森の崩壊」「ペルム紀末の大絶滅」など28の節目を越えると知らせが出る。
3. **潜る・降りる**：その場所の環境（陸・干潟・浅い海・大陸棚・外洋の深海）の断面に入る。水深に応じて暗くなり、深い海ではライトが要る。陸は時代によって、植物のない岩の大地・緑の岸辺・森・石炭紀の湿地林・氷河・ペルム紀の砂漠に変わる。
4. **撮影**：生きものを大きく・真ん中に・明るく写すほど ★1〜3。撮影成功でカードがめくられ、光の粒とともに星が順番に現れる。複数の対象はカードを一枚ずつ表示し、タップ・Enterで次へ、Escですべて閉じられる。図鑑への記録は撮影時に保存される。逃げる魚、巣穴に引っ込む虫には、ゆっくり近づく。上空からは大陸の全体や大噴火を撮れる。
5. **宿題**：トキ先生から36の課題が出る（カンブリア紀10・オルドビス紀5・シルル紀4・デボン紀7・石炭紀5・ペルム紀5）。宿題のカードの「行く」を押すと、目的の生きものがいた時代と場所へカプセルが向かう。観察中は宿題の生きものが「!」の印で示される。

## 収録内容

- **大陸（9）**：ゴンドワナ・ローレンシア・バルティカ・アヴァロニア・シベリア・南中国・北中国・カザフの島々・タリム。キーフレームの間を補間して動き、アヴァロニア→バルティカ（4億4500万年前）→ローレンシア（4億2000万年前）、ゴンドワナ（3億500万年前）、カザフ・タリム・シベリアの順にぶつかって一緒に動く（パンゲア）。
- **化石の産地（39）**：カンブリア紀10（フォーチュン岬・澄江・バージェスなど）、オルドビス紀4（フェズアタ・ボリビア・サンクトペテルブルク・シンシナティ）、シルル紀5（ストーンヘイブン・ゴトランド・ダドリー・曲靖・ニューヨークの入り江）、デボン紀9（ライニー・フンスリュック・ギルボア・ゴーゴー・ミグアシャ・エルズミーア島・東グリーンランド・クリーブランド・アイフェル）、石炭紀5（イースト・カークトン・ベア・ガルチ・ジョギンズ・メゾンクリーク・コマントリー）、ペルム紀6（イラチ・テキサス・キャピタン礁・カルー・ヴャトカ・シベリアの大噴火）。
- **生きもの（99）**：カンブリア紀36（アノマロカリス・オパビニア・ハルキゲニアなど）、オルドビス紀13（エーギロカシス・カメロケラス・サカバンバスピス・筆石・ウミユリなど）、シルル紀9（クックソニア・ユーリプテルス・グイユー・バラグワナチアなど）、デボン紀17（ダンクルオステウス・ティクターリク・アカントステガ・アーケオプテリス・プロトタキシーテスなど）、石炭紀12（メガネウラ・アースロプレウラ・鱗木・ツリモンストラムなど）、ペルム紀12（ディメトロドン・ヘリコプリオン・イノストランケビア・リストロサウルスなど）。
- **現象（13）**：ゴンドワナ・ローレンシア・ユーラメリカ・パンゲア（上空から全体を撮る）、カルカリンジとシベリアの大噴火、植物のない大地・最初の緑の岸辺・最初の森・石炭紀の湿地林・ゴンドワナの氷河（2つ）・パンゲアの砂漠（陸に降りて撮る）。

時代・産地・大きさ・古地理はゲーム用に簡略化したおおよそのものです（Scotese・Torsvik などの古地理図や各化石産地の資料を参考にした）。

## 復元アートワーク

図鑑112項目（生物・生痕99、現象13）、時代別遠景16枚、タイトル・浅海・深海・トキ先生の計132枚を画像生成で制作しています。生物や景観は殻や軟体部の質感、海中の光、原始の地形を表現した復元イメージで、色や軟体部、古地理の細部には想像を含みます。トキ先生は紫色の髪と丸い眼鏡を残し、子どもに親しみやすい絵本風の先生として描いています。

画像は `assets/artwork/` に保存し、一覧と詳細では縦横比を保って全体を表示します。タイトルと観察中の遠景にも生成画像を使用します。ゲーム本体に埋め込むため、別の画像配信サーバーは不要です。各画像は初めて表示するときにデコードしてキャッシュします。

生成に使ったプロンプト一式は `assets/artwork/manifest.json` に記録しています。元の生成PNGがある環境では `python tools/prepare_artwork.py`（Pillowが必要）で配信用JPEGと確認用一覧 `output/artwork/contact-sheet.jpg` を作れます。通常のビルドではPythonは不要です。

観察画面には、生物・生痕99項目、カプセル、岩、砂地の102枚を `assets/units/` に追加しています。生物・カプセル・岩は背景透過PNG、砂地は連続する専用テクスチャです。魚の尾、節足動物の脚・遊泳肢、クラゲの傘・触手などは画像のメッシュを変形して動かします。固着する生物・岩・生痕は動かさず、移動・逃避・巣穴への出入りは従来の行動と連動します。描画と撮影の採点には共通の画像範囲を使います。

観察用素材の生成プロンプトは `assets/units/manifest.json`、画像の準備は `python tools/prepare_units.py`、確認用一覧は `output/artwork/unit-contact-sheet.jpg` です。画像・メッシュはWebGL2とDirect3Dの両方で描画します。

### 画像を足す

画像は名前（slug）で引きます。`build.rs` が `assets/artwork/*.jpg` と `assets/units/*.png` を探して自動で組み込むので、同じ名前のファイルを置いてビルドし直すだけで使われます（Rust のコードの変更は不要）。無い画像は `src/art.rs` の手描きの絵で代わりに描きます（観察の場面・図鑑・撮影カードとも）。

今回追加したオルドビス紀〜ペルム紀の画像（図鑑の画像72枚・観察用スプライト63枚、時代別遠景16枚）の一覧と生成プロンプトは [docs/asset-requests.md](docs/asset-requests.md)（ツール用は `assets/requests.json`）。この一覧はゲームのデータから `cargo test --lib write_asset_requests -- --ignored` で作り直せます。

## 操作

| | マウス・キーボード | タッチ |
|---|---|---|
| 地図 | クリックで移動／WASD で移動・ドラッグや矢印キーで地図を動かす・ホイールで拡大縮小 | タップで移動・なぞる・2本指で拡大縮小 |
| 時代 | 年表をクリック、`,` `.` で期を移る | 年表をタップ・◀ ▶ |
| 潜る | Enter | 「潜る／降りる」 |
| 観察 | WASD・矢印・マウスを押した方へ進む／Shift で加速／ホイール・Q/E でズーム／L でライト／F で海底へ | 触れた方へ進む・＋－・ボタン |
| 撮影 | Space・右クリック | 撮影ボタン |
| 画面 | F1 宿題・F2 図鑑・F3 操作・Esc 浮上／閉じる・Ctrl＋＋/－ 文字の大きさ・F11 全画面 | 上のボタン |

進み具合は自動で記録される（ブラウザの IndexedDB。タイトル画面の「つづきから」）。操作画面からファイル（.yyesav）に書き出し・読み込みできる。

## 構成

| ファイル | 内容 |
|---|---|
| `src/earth.rs` | 大陸の形・位置・移動（キーフレーム）、地形の高さ、環境の判定、化石の産地、地球史の節目と期 |
| `src/life.rs` | 生きもの99種と現象13のデータ（時代・すみか・産地・ふるまい・説明）、どこにいるかの判定、陸の景色の判定 |

| `src/dive.rs` | 観察の場面：海底の地形、生きものの動き（泳ぐ・歩く・巣穴・漂う・逃げる）、カプセル、明るさとライト、写真の採点 |
| `src/mission.rs` | 宿題（トキ先生の課題） |
| `src/progress.rs` | 図鑑の星・宿題・時と場所、その記録の読み書き |
| `src/game.rs` | 画面と操作：タイトル、地図、時間旅行、観察、図鑑、宿題、操作説明、写真、知らせ |
| `src/lang.rs` | 日本語・英語・中国語 |
| `src/gfx.rs`・`src/web.rs`・`src/platform.rs`・`web/` | ブラウザ版の描画・入力・記録（YYMongolia から流用） |
| `src/main.rs`・`src/win/*` | Windows 版（YYMongolia から流用） |
| `tools/make_icons.py` | アイコンを作る |

## テスト

```
cargo test --release --lib
```

大陸どうしが（ぶつかる縁を除いて）重ならないこと、ぶつかった大陸が一緒に動くこと、産地がふさわしい環境にあること、すべての生きもの・現象に会いに行けること、宿題の対象がその紀にいること、カンブリア紀だけの版の記録を読めること、記録の読み書き、場面での写真の採点、すべての画面の描画などを確かめる。
地図を画像に書き出して確かめるには `YY_DUMP=出力先 cargo test --release --lib dump_map -- --ignored`。
