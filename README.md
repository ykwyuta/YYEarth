# 地球史図鑑 — 時をめぐる観察カプセル（YYEarth）

西暦2650年。あなたは時間旅行学校の生徒です。今学期の宿題は「地球史図鑑」づくり。
時空観察カプセルに乗って過去の地球へ行き、海の中や陸のさまざまな場所で生きものを撮影し、図鑑に収録します。

**第1〜6巻：古生代**（カンブリア紀・オルドビス紀・シルル紀・デボン紀・石炭紀・ペルム紀）と**第7〜9巻：中生代**（三畳紀・ジュラ紀・白亜紀）、**第10〜12巻：新生代**（古第三紀・新第三紀・第四紀）を収録。5億3880万年前から1万年前（完新世）までを旅できます。

> 図鑑449項目（生物・生痕427、現象22）を収録。全449項目の図鑑画像、生物・生痕427項目の観察用スプライト、時代別遠景34枚を組み込み済みです。新生代の追加画像276点もすべて収録しています。三畳紀・ジュラ紀・白亜紀を含む全12巻・63課題を遊べます。画像の対応一覧と生成プロンプトは [docs/asset-requests.md](docs/asset-requests.md) にあります。

[YYMongolia](https://github.com/ykwyuta/yyMongolia) の描画・入力・記録の層（Rust → WebAssembly の WebGL2 / Canvas2D、Windows 版の Direct3D11 / Direct2D、IndexedDB と %APPDATA% の記録、タッチ操作、日本語・英語・中国語）を使い、ゲーム本体を作り直しました。復元画像のJPEG・PNGデコードには `image` クレートを使用します。

## 遊ぶ・ビルドする

```
bash build.sh                      # Rust が無ければ rustup で導入し、dist/ に静的サイトを出力
cd dist && python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開く（WebGL2 が必要）。`?lang=en` / `?lang=zh` で表示言語、`?touch=1` でタッチ向けの画面を試せます。

更新したのに古い版が表示されるときは、タイトル画面か操作説明（F3）の「キャッシュを消して再読み込み」を2回押す。Service Worker・Cache Storage を消し、ページと wasm を取り直して読み込み直す（記録と言語の設定は残る）。

Windows 版：`cargo run --release --bin yyearth-win`（記録は `%APPDATA%\yyearth\saves`）。

Windowsでブラウザ版をローカル確認するときは `python tools/serve.py` で `http://localhost:8765/` を開けます（`dist/` を配信し、JavaScriptとWasmのMIME型も設定します）。

ブラウザ版のビルドにはNode.jsも必要です。画像を含むWasmが大きい場合は、公開先の1ファイル上限に収まるよう24MiBごとに分割し、ブラウザで結合して起動します。通常のビルドで配信設定とファイル一覧も自動的に出力されます。

Cloudflare への公開は YYMongolia と同じ（`bash build.sh && npx wrangler deploy`、または Pages でビルドコマンド `npm run build`・出力 `dist`）。

## ゲームの流れ

1. **地図（上空）**：古生代・中生代・新生代の地球を正距円筒図法で表示。クリック（タップ）した場所へカプセルが飛ぶ。シルル紀からは陸に緑が広がり、氷河時代には南極に氷が現れる。
2. **時間旅行**：画面下の年表で時代を選ぶ。上の細い帯が古生代・中生代・新生代の12の紀（クリックでその紀へ）、下の帯がいまの紀の期（全71）。大陸はキーフレームの間を動き、ぶつかると一緒に動いて、ユーラメリカ大陸、やがて超大陸パンゲアになる。中生代にはパンゲアが裂け、北アメリカとアフリカの間に大西洋が開き（1億9000万年前〜）、ゴンドワナが南極・南アメリカ・インド・オーストラリアに分かれていく。「三葉虫の登場」「オルドビス紀末の大絶滅」「最初の森」「ひれから足へ」「石炭紀の森の崩壊」「ペルム紀末の大絶滅」「最初の恐竜」「大西洋の誕生」「花の咲く植物の登場」「白亜紀末の大絶滅」など46の節目を越えると知らせが出る。
3. **潜る・降りる**：その場所の環境（陸・干潟・浅い海・大陸棚・外洋の深海）の断面に入る。水深に応じて暗くなり、深い海ではライトが要る。陸は時代によって、植物のない岩の大地・緑の岸辺・森・石炭紀の湿地林・氷河・ペルム紀の砂漠・恐竜時代の針葉樹とシダの森・花の咲く森に変わる。
4. **撮影**：生きものを大きく・真ん中に・明るく写すと図鑑に収録される（小さすぎる・暗すぎる写真は収録されない）。撮影成功でカードがめくられ、光の粒とともに「図鑑に収録」の印が現れる。複数の対象はカードを一枚ずつ表示し、タップ・Enterで次へ、Escですべて閉じられる。図鑑への記録は撮影時に保存される。逃げる魚、巣穴に引っ込む虫には、ゆっくり近づく。上空からは大陸の全体や大噴火を撮れる。
5. **探索レーダー**：図鑑の項目の「◎ レーダーで探す」を押すと、いまの時代にその生きもの（現象）に会える場所が地図の上で光り、年表にはいた時代が金色で示される。いない時代なら「その時代へ行く」、いれば「いちばん近い所へ」でカプセルが向かい、真下にいると「潜る」よう知らせる。観察中は右下のレーダーに、まわりの生きもの（未収録は水色、探しているものは金色）と距離が出て、画面の外にいれば端に矢印が出る。
6. **宿題**：トキ先生から63の課題が出る（カンブリア紀10・オルドビス紀5・シルル紀4・デボン紀7・石炭紀5・ペルム紀5・三畳紀5・ジュラ紀5・白亜紀5・古第三紀4・新第三紀4・第四紀4）。順番の決まりはなく、宿題の一覧（F1）の紀のタブから好きな宿題を選んで取り組める。宿題のカードの ◀ ▶ でまだ合格していない宿題を切り替えられ、選んでいない宿題も対象を撮れば合格する。宿題のカードの「行く」を押すと、目的の生きものがいた時代と場所へカプセルが向かう。観察中は宿題の生きものが「!」の印で示される。

## 新生代（第10〜12巻）

6600万年前から1万年前まで、古第三紀・新第三紀・第四紀を追加しました。暁新世・始新世・漸新世・中新世・鮮新世・更新世・完新世を選べます。第四紀の最後の目盛りで、ちょうど1万年前へ移動できます。年表上段は各紀を同じ幅で表示し、短い第四紀も選びやすくしています。

マンモス、スミロドン、バシロサウルス、メガロドン、初期人類など、生きもの132項目、景観3項目、産地10地点、節目6件、宿題12件を追加。図鑑は合計449項目（生きもの427・現象22）、宿題は全63件です。既存の図鑑の収録と宿題の達成状況は引き継がれます。新生代は初期の36項目から72項目を追加して108項目へ拡充し、さらに豪州・南極を中心とする古第三紀の24項目を補強しました。

新生代の全276素材（生きもの132項目の図鑑画像・透過スプライト各132点、現象3点、専用遠景9点）を内蔵ImageGenで制作し、ゲームへ組み込みました。生成プロンプトは `assets/artwork/manifest.json` と `assets/units/manifest.json` に記録しています。南方の補強内容と根拠は [古第三紀の豪州・南極](docs/paleogene-southern-coverage.md)、地域・世・陸海・生物群ごとの集計は [新生代の収録バランス](docs/cenozoic-balance.md) にあります。年代・分布・古地理の簡略化と参考資料は [新生代の収録内容](docs/cenozoic-fauna.md) を参照してください。

## 復元アートワーク

図鑑449項目（生物・生痕427、現象22）、時代別遠景34枚、タイトル・浅海・深海・トキ先生の画像を収録しています。古生代・中生代の広域動物群12項目には既存の復元画像・スプライトを代表像として再利用しています（24ファイル）。生物や景観は殻や軟体部の質感、海中の光、原始の地形を表現した復元イメージで、色や軟体部、古地理の細部には想像を含みます。トキ先生は紫色の髪と丸い眼鏡を残し、子どもに親しみやすい絵本風の先生として描いています。

画像は `assets/artwork/` に保存し、一覧と詳細では縦横比を保って全体を表示します。タイトルと観察中の遠景にも生成画像を使用します。ゲーム本体に埋め込むため、別の画像配信サーバーは不要です。各画像は初めて表示するときにデコードしてキャッシュします。

生成に使ったプロンプト一式は `assets/artwork/manifest.json` に記録しています。元の生成PNGがある環境では `python tools/prepare_artwork.py`（Pillowが必要）で配信用JPEGと確認用一覧 `output/artwork/contact-sheet.jpg` を作れます。通常のビルドではPythonは不要です。

観察画面には、生物・生痕427項目、カプセル、岩、砂地の430枚を `assets/units/` に追加しています。生物・カプセル・岩は背景透過PNG、砂地は連続する専用テクスチャです。魚の尾、節足動物の脚・遊泳肢、クラゲの傘・触手などは画像のメッシュを変形して動かします。固着する生物・岩・生痕は動かさず、移動・逃避・巣穴への出入りは従来の行動と連動します。描画と撮影の採点には共通の画像範囲を使います。

メッシュの変形は、魚・海生爬虫類の尾、クラゲや虫状の軟らかい体、節足動物の脚・遊泳肢、飛翔する鳥・翼竜・昆虫の羽ばたきなどに限定しています。人・陸の哺乳類・恐竜・地上を歩く四肢動物や翼竜、飛べない鳥には適用せず、画像の形を保って移動します。専用の変形を持たない生きものにも、共通の波打つ変形は適用しません。

観察用素材の生成プロンプトは `assets/units/manifest.json`、画像の準備は `python tools/prepare_units.py`、確認用一覧は `output/artwork/unit-contact-sheet.jpg` です。画像・メッシュはWebGL2とDirect3Dの両方で描画します。

### 画像を足す

画像は名前（slug）で引きます。`build.rs` が `assets/artwork/*.jpg` と `assets/units/*.png` を探して自動で組み込むので、同じ名前のファイルを置いてビルドし直すだけで使われます（Rust のコードの変更は不要）。無い画像は `src/art.rs` の手描きの絵で代わりに描きます（観察の場面・図鑑・撮影カードとも）。

全12紀の画像（図鑑画像449枚・観察用スプライト427枚・時代別遠景34枚）の一覧と生成プロンプトは [docs/asset-requests.md](docs/asset-requests.md)（ツール用は `assets/requests.json`）。この一覧はゲームのデータから `cargo test --lib write_asset_requests -- --ignored` で作り直せます。

## 読み上げ・音声ガイド

日本語版の図鑑は、全449項目に600字以上の読みものを収録しています。生物・生痕は個別の紹介に加え、「なかまの体とくらし」「この時代の地球」「化石から考えよう」を読めます。分類群の共通解説では、その項目だけに確定した性質と取り違えないよう、仲間全体のしくみや研究の考え方を説明しています。大陸・森林・氷床・噴火など22の現象には、それぞれのしくみと証拠の説明があります。

長い本文は画面の大きさに合わせてページに分けます。「前のページ」「次のページ」、上下キー、Page Up / Page Down、Space（次へ）、マウスホイールで読み進められます。タッチ端末ではページボタンを使います。左右キーは前後の図鑑項目へ移動します。音声は開いているページを読み上げます。英語・中国語版では従来の翻訳を同じページ表示で読めます。本文の構成と確認資料は [図鑑の読みもの](docs/guide-readings.md) にあります。

音声ガイドは最初からオンです。ブラウザ版では、最初に画面を押すかキーを押すと読み上げが始まります。先生の説明、宿題、図鑑の名前と説明、撮影結果を読み上げ、地図と観察画面で遊び方を案内します。マウスをボタンや生きものの絵に少し置くと名前も聞けます。

iPad・iPhoneでは、画面をタップして指を離すと音声を初期化します。読み込み中に先にタップした場合も、その後の案内を再生できます。

日本語の誤読は `src/speech_ja.tsv` の共通読み辞書で補正します。地質年代、生物の分類、地名、図鑑の説明、宿題、操作案内の熟語を登録し、音声に渡す文章だけをかな表記に変換します。画面の漢字はそのままで、ブラウザ版とWindows版に適用します。`src/speech.rs` は同じ位置で最も長く一致する表記を優先し、置換後の文字列を再置換しません。「方」「上手」「大人」など、文脈で読みが変わる語は句ごとに登録し、一文字の漢字は一括置換しません。

辞書は「表記・タブ・かなの読み」を1行ずつ追加します。`python tools/audit_readings.py --check` は日本語の `L`・`t!`・`tf!` の通常文字列を走査し、補正後も漢字が2文字以上続く箇所をファイルと行番号付きで報告します。CIでも実行します。Rustのテストでも図鑑・宿題・地質年代・観察地点の実データ、辞書の重複、長い語の優先、多義語、他言語の維持を検証します。この検査は単漢字や動的な文の組み立て、端末の発音・アクセントを保証するものではありません。

左上の 🔊／🔇（F5）でオン・オフ、↻（F4）でいまの案内を聞き直せます。設定は端末に保存されます。音声オンの間は撮影カードが自動で閉じず、子どものペースで進められます。日本語・英語・中国語の表示に合わせて端末の音声を使います。ブラウザの音声合成機能、またはWindowsのSAPIと読み上げ音声が必要です。端末に対応する音声がない場合や音声合成が非対応の場合は、読み上げを利用できないことがあります。

## テスト

```
cargo test --release --lib
cargo test --release --lib --features headless  # Windowsでも画面なしで移動・撮影・描画を検証
npm run test:voice                 # 音声ガイド・iPad向け初期化の回帰テスト
python tools/audit_readings.py --check  # 日本語熟語の読み辞書の登録漏れ
```

大陸どうしが（ぶつかる縁を除いて）重ならないこと、ぶつかった大陸が一緒に動くこと、産地がふさわしい環境にあること、すべての生きもの・現象に会いに行けること、宿題の対象がその紀にいること、カンブリア紀だけの版・古生代212種版・中生代283項目版の記録を読めること、中生代の全期の境界・中間時点で世界の陸を5度刻みに調べて4群以上の動物がいること、中生代15課題の対象を訪問・撮影して保存できること、記録の読み書き、場面での写真の採点、すべての画面の描画などを確かめる。
地図を画像に書き出して確かめるには `YY_DUMP=出力先 cargo test --release --lib dump_map -- --ignored`。

中生代追加分の素材検査と確認画像は `python tools/audit_mesozoic.py` で作成できます（Pillowが必要）。生成した原画像は `tools/ingest_mesozoic.py` で画像とプロンプトの記録を一緒に取り込めます。

新生代の276素材は `python tools/audit_cenozoic_art.py` で欠落・デコード・透過を検査し、`output/cenozoic-generation/review/` に確認用一覧を出力できます。制作内容は [新生代の画像](docs/cenozoic-artwork.md) を参照してください。
