# 地球史図鑑 — 時をめぐる観察カプセル（YYEarth）

西暦2650年。あなたは時間旅行学校の生徒です。今学期の宿題は「地球史図鑑」づくり。
時空観察カプセルに乗って過去の地球へ行き、海の中や陸のさまざまな場所で生きものを撮影し、図鑑に収録します。

**第1〜6巻：古生代**（カンブリア紀・オルドビス紀・シルル紀・デボン紀・石炭紀・ペルム紀）と**第7〜9巻：中生代**（三畳紀・ジュラ紀・白亜紀）、5億3880万〜6600万年前を収録。新生代から現代までは今後追加予定です。

> 図鑑314項目（生物・生痕295、現象19）、観察用スプライト295項目、時代別遠景25枚の画像を収録しています。中生代用の追加画像157点もすべて組み込み済みです。三畳紀・ジュラ紀・白亜紀を含む全9巻・51課題を遊べます。画像の対応一覧と生成プロンプトは [docs/asset-requests.md](docs/asset-requests.md) にあります。

[YYMongolia](https://github.com/ykwyuta/yyMongolia) の描画・入力・記録の層（Rust → WebAssembly の WebGL2 / Canvas2D、Windows 版の Direct3D11 / Direct2D、IndexedDB と %APPDATA% の記録、タッチ操作、日本語・英語・中国語）を使い、ゲーム本体を作り直しました。復元画像のJPEG・PNGデコードには `image` クレートを使用します。

## 遊ぶ・ビルドする

```
bash build.sh                      # Rust が無ければ rustup で導入し、dist/ に静的サイトを出力
cd dist && python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開く（WebGL2 が必要）。`?lang=en` / `?lang=zh` で表示言語、`?touch=1` でタッチ向けの画面を試せます。

更新したのに古い版が表示されるときは、タイトル画面か操作説明（F3）の「キャッシュを消して再読み込み」を2回押す。Service Worker・Cache Storage を消し、ページと wasm を取り直して読み込み直す（記録と言語の設定は残る）。

Windows 版：`cargo run --release --bin yyearth-win`（記録は `%APPDATA%\yyearth\saves`）。

Windowsでブラウザ版をローカル確認するときは `python tools/serve.py` で `http://localhost:8765/` を開けます（`dist/` を配信し、JavaScriptとWasmのMIME型も設定します）。

ブラウザ版のビルドにはNode.jsも必要です。画像を含むWasmが大きい場合は、公開先の1ファイル上限に収まるよう24MiBごとに分割し、ブラウザで結合して起動します。通常のビルドで配信設定とファイル一覧も自動的に出力されます。

Cloudflare への公開は YYMongolia と同じ（`bash build.sh && npx wrangler deploy`、または Pages でビルドコマンド `npm run build`・出力 `dist`）。

## ゲームの流れ

1. **地図（上空）**：古生代・中生代の地球を正距円筒図法で表示。クリック（タップ）した場所へカプセルが飛ぶ。シルル紀からは陸に緑が広がり、氷河時代には南極に氷が現れる。
2. **時間旅行**：画面下の年表で時代を選ぶ。上の細い帯が古生代・中生代の9つの紀（クリックでその紀へ）、下の帯がいまの紀の期（全62）。大陸はキーフレームの間を動き、ぶつかると一緒に動いて、ユーラメリカ大陸、やがて超大陸パンゲアになる。中生代にはパンゲアが裂け、北アメリカとアフリカの間に大西洋が開き（1億9000万年前〜）、ゴンドワナが南極・南アメリカ・インド・オーストラリアに分かれていく。「三葉虫の登場」「オルドビス紀末の大絶滅」「最初の森」「ひれから足へ」「石炭紀の森の崩壊」「ペルム紀末の大絶滅」「最初の恐竜」「大西洋の誕生」「花の咲く植物の登場」「白亜紀末の大絶滅」など40の節目を越えると知らせが出る。
3. **潜る・降りる**：その場所の環境（陸・干潟・浅い海・大陸棚・外洋の深海）の断面に入る。水深に応じて暗くなり、深い海ではライトが要る。陸は時代によって、植物のない岩の大地・緑の岸辺・森・石炭紀の湿地林・氷河・ペルム紀の砂漠・恐竜時代の針葉樹とシダの森・花の咲く森に変わる。
4. **撮影**：生きものを大きく・真ん中に・明るく写すと図鑑に収録される（小さすぎる・暗すぎる写真は収録されない）。撮影成功でカードがめくられ、光の粒とともに「図鑑に収録」の印が現れる。複数の対象はカードを一枚ずつ表示し、タップ・Enterで次へ、Escですべて閉じられる。図鑑への記録は撮影時に保存される。逃げる魚、巣穴に引っ込む虫には、ゆっくり近づく。上空からは大陸の全体や大噴火を撮れる。
5. **探索レーダー**：図鑑の項目の「◎ レーダーで探す」を押すと、いまの時代にその生きもの（現象）に会える場所が地図の上で光り、年表にはいた時代が金色で示される。いない時代なら「その時代へ行く」、いれば「いちばん近い所へ」でカプセルが向かい、真下にいると「潜る」よう知らせる。観察中は右下のレーダーに、まわりの生きもの（未収録は水色、探しているものは金色）と距離が出て、画面の外にいれば端に矢印が出る。
6. **宿題**：トキ先生から51の課題が出る（カンブリア紀10・オルドビス紀5・シルル紀4・デボン紀7・石炭紀5・ペルム紀5・三畳紀5・ジュラ紀5・白亜紀5）。順番の決まりはなく、宿題の一覧（F1）の紀のタブから好きな宿題を選んで取り組める。宿題のカードの ◀ ▶ でまだ合格していない宿題を切り替えられ、選んでいない宿題も対象を撮れば合格する。宿題のカードの「行く」を押すと、目的の生きものがいた時代と場所へカプセルが向かう。観察中は宿題の生きものが「!」の印で示される。

## 収録内容

- **大陸（13）**：ゴンドワナ・ローレンシア・バルティカ・アヴァロニア・シベリア・南中国・北中国・カザフの島々・タリムと、ゴンドワナのかけら（南アメリカ・インド・南極・オーストラリア）。キーフレームの間を補間して動き、アヴァロニア→バルティカ（4億4500万年前）→ローレンシア（4億2000万年前）、ゴンドワナ（3億500万年前）、カザフ・タリム・シベリアの順にぶつかって一緒に動く（パンゲア）。ゴンドワナは一つの地形を切り分けたかけらでできていて、古生代はすき間なく一つに見え、中生代にアフリカ（1億9000万年前）・南極（1億6500万年前）・南アメリカ（1億3500万年前）・インド（1億3000万年前）・オーストラリア（8500万年前）の順に離れていく。中国の地塊はジュラ紀にアジアにくっつく。
- **化石の産地（58）**：カンブリア紀10（フォーチュン岬・澄江・バージェスなど）、オルドビス紀4（フェズアタ・ボリビア・サンクトペテルブルク・シンシナティ）、シルル紀5（ストーンヘイブン・ゴトランド・ダドリー・曲靖・ニューヨークの入り江）、デボン紀9（ライニー・フンスリュック・ギルボア・ゴーゴー・ミグアシャ・エルズミーア島・東グリーンランド・クリーブランド・アイフェル）、石炭紀5（イースト・カークトン・ベア・ガルチ・ジョギンズ・メゾンクリーク・コマントリー）、ペルム紀6（イラチ・テキサス・キャピタン礁・カルー・ヴャトカ・シベリアの大噴火）、三畳紀5（イスチグアラスト・モンテ・サン・ジョルジョ・ゴーストランチ・トロッシンゲン・CAMP）、ジュラ紀5（ライム・リージス・ホルツマーデン・燕遼・モリソン・ゾルンホーフェン）、白亜紀9（熱河・ウィールド・ケムケム・パタゴニア・西部内陸海路・ゴビ・ヘルクリーク・デカン・チクシュルーブ）。
- **生きもの（295）**：カンブリア紀44（アノマロカリス・オパビニア・ハルキゲニア・ワプティア・エルラシア・ミロクンミンギアなど）、オルドビス紀31（エーギロカシス・サカバンバスピス・ペンテコプテルス・最古のカブトガニ・ウミリンゴ・古いウニなど）、シルル紀26（クックソニア・ユーリプテルス・プテリゴトゥス・ブロントスコルピオ・クサリサンゴなど）、デボン紀39（ダンクルオステウス・ティタニクティス・ティクターリク・パンデリクティス・最古の昆虫・アッテルコプスなど）、石炭紀36（メガネウラ・アースロプレウラ・リゾドゥス・ファルカトゥス・ペトロラコサウルス・メガラクネなど）、ペルム紀35（ディメトロドン・ヘリコプリオン・プリオノスクス・コエルロサウラヴス・メガネウロプシス・エステメノスクスなど）、三畳紀31（リストロサウルス・エオラプトル・コエロフィシス・プラテオサウルス・ミクソサウルス・タニストロフェウス・ポストスクスなど）、ジュラ紀25（アロサウルス・ステゴサウルス・ディプロドクス・ブラキオサウルス・始祖鳥・イクチオサウルス・プレシオサウルス・アンモナイトなど）、白亜紀28（ティラノサウルス・トリケラトプス・スピノサウルス・アルゼンチノサウルス・ヴェロキラプトル・モササウルス・プテラノドン・ケツァルコアトルス・花の咲く植物など）。各紀には、産地に限らず世界中や暖かい海に広く出会う「どこにでもいた生きもの」（巻貝・二枚貝・腕足動物・三葉虫・サンゴ・オウムガイ・ふつうの魚・シダや木など）も入れている。
- **現象（19）**：ゴンドワナ・ローレンシア・ユーラメリカ・パンゲア・ローラシア（上空から全体を撮る）、カルカリンジ・シベリア・中央大西洋（CAMP）・デカンの大噴火とチクシュルーブの衝突（上空から撮る）、植物のない大地・最初の緑の岸辺・最初の森・石炭紀の湿地林・ゴンドワナの氷河（2つ）・パンゲアの砂漠・恐竜時代の針葉樹とシダの森・花の咲く森（陸に降りて撮る）。

中生代の陸には、特定の化石産地以外でも観察できる広域動物群12項目（ゴキブリ型昆虫・ヤスデ・サソリ・小型爬虫類・キノドン類・哺乳形類・ムカシトカゲ類・小型獣脚類・竜脚形類・小型鳥脚類・翼竜・ワニ形類）を追加しています。これらは単一種の全世界分布を示すものではなく、時代と地域によって入れ替わる近縁の動物をまとめた観察用の項目です。姿・大きさは代表例です。エオラプトル・ヘレラサウルス・アルゼンチノサウルス・ギガノトサウルスは、産地のほか南アメリカ大陸でも出会えます。

時代・産地・大きさ・古地理はゲーム用に簡略化したおおよそのものです（Scotese・Torsvik などの古地理図や各化石産地の資料を参考にした）。

## 復元アートワーク

図鑑314項目（生物・生痕295、現象19）、時代別遠景25枚、タイトル・浅海・深海・トキ先生の画像を収録しています。画像生成で制作した331枚に加え、広域動物群12項目には既存の復元画像・スプライトを代表像として再利用しています（追加24ファイル）。生物や景観は殻や軟体部の質感、海中の光、原始の地形を表現した復元イメージで、色や軟体部、古地理の細部には想像を含みます。トキ先生は紫色の髪と丸い眼鏡を残し、子どもに親しみやすい絵本風の先生として描いています。

画像は `assets/artwork/` に保存し、一覧と詳細では縦横比を保って全体を表示します。タイトルと観察中の遠景にも生成画像を使用します。ゲーム本体に埋め込むため、別の画像配信サーバーは不要です。各画像は初めて表示するときにデコードしてキャッシュします。

生成に使ったプロンプト一式は `assets/artwork/manifest.json` に記録しています。元の生成PNGがある環境では `python tools/prepare_artwork.py`（Pillowが必要）で配信用JPEGと確認用一覧 `output/artwork/contact-sheet.jpg` を作れます。通常のビルドではPythonは不要です。

観察画面には、生物・生痕295項目、カプセル、岩、砂地の298枚を `assets/units/` に追加しています。生物・カプセル・岩は背景透過PNG、砂地は連続する専用テクスチャです。魚の尾、節足動物の脚・遊泳肢、クラゲの傘・触手などは画像のメッシュを変形して動かします。固着する生物・岩・生痕は動かさず、移動・逃避・巣穴への出入りは従来の行動と連動します。描画と撮影の採点には共通の画像範囲を使います。

観察用素材の生成プロンプトは `assets/units/manifest.json`、画像の準備は `python tools/prepare_units.py`、確認用一覧は `output/artwork/unit-contact-sheet.jpg` です。画像・メッシュはWebGL2とDirect3Dの両方で描画します。

### 画像を足す

画像は名前（slug）で引きます。`build.rs` が `assets/artwork/*.jpg` と `assets/units/*.png` を探して自動で組み込むので、同じ名前のファイルを置いてビルドし直すだけで使われます（Rust のコードの変更は不要）。無い画像は `src/art.rs` の手描きの絵で代わりに描きます（観察の場面・図鑑・撮影カードとも）。

全9紀の画像（図鑑の画像302枚・観察用スプライト283枚、時代別遠景25枚）の一覧と生成プロンプトは [docs/asset-requests.md](docs/asset-requests.md)（ツール用は `assets/requests.json`）。この一覧はゲームのデータから `cargo test --lib write_asset_requests -- --ignored` で作り直せます。

## 読み上げ・音声ガイド

音声ガイドは最初からオンです。ブラウザ版では、最初に画面を押すかキーを押すと読み上げが始まります。先生の説明、宿題、図鑑の名前と説明、撮影結果を読み上げ、地図と観察画面で遊び方を案内します。マウスをボタンや生きものの絵に少し置くと名前も聞けます。

iPad・iPhoneでは、画面をタップして指を離すと音声を初期化します。読み込み中に先にタップした場合も、その後の案内を再生できます。

左上の 🔊／🔇（F5）でオン・オフ、↻（F4）でいまの案内を聞き直せます。設定は端末に保存されます。音声オンの間は撮影カードが自動で閉じず、子どものペースで進められます。日本語・英語・中国語の表示に合わせて端末の音声を使います。ブラウザの音声合成機能、またはWindowsのSAPIと読み上げ音声が必要です。端末に対応する音声がない場合や音声合成が非対応の場合は、読み上げを利用できないことがあります。

## テスト

```
cargo test --release --lib
npm run test:voice                 # 音声ガイド・iPad向け初期化の回帰テスト
```

大陸どうしが（ぶつかる縁を除いて）重ならないこと、ぶつかった大陸が一緒に動くこと、産地がふさわしい環境にあること、すべての生きもの・現象に会いに行けること、宿題の対象がその紀にいること、カンブリア紀だけの版・古生代212種版・中生代283項目版の記録を読めること、中生代の全期の境界・中間時点で世界の陸を5度刻みに調べて4群以上の動物がいること、中生代15課題の対象を訪問・撮影して保存できること、記録の読み書き、場面での写真の採点、すべての画面の描画などを確かめる。
地図を画像に書き出して確かめるには `YY_DUMP=出力先 cargo test --release --lib dump_map -- --ignored`。

中生代追加分の素材検査と確認画像は `python tools/audit_mesozoic.py` で作成できます（Pillowが必要）。生成した原画像は `tools/ingest_mesozoic.py` で画像とプロンプトの記録を一緒に取り込めます。
