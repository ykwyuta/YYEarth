# 地球史図鑑 — 時をめぐる観察カプセル（YYEarth）

西暦2650年。あなたは時間旅行学校の生徒です。今学期の宿題は「地球史図鑑」づくり。
時空観察カプセルに乗って過去の地球へ行き、海の中や陸のさまざまな場所で生きものを撮影し、図鑑に収録します。

**第1巻：古生代カンブリア紀**（5億3880万〜4億8540万年前）を収録。オルドビス紀から現代までは今後追加予定です。

[YYMongolia](https://github.com/ykwyuta/yyMongolia) の描画・入力・記録の層（Rust → WebAssembly の WebGL2 / Canvas2D、Windows 版の Direct3D11 / Direct2D、IndexedDB と %APPDATA% の記録、タッチ操作、日本語・英語・中国語）をそのまま使い、ゲーム本体を作り直しました。外部クレートは使いません（Windows 版の `windows` クレートを除く）。

## 遊ぶ・ビルドする

```
bash build.sh                      # Rust が無ければ rustup で導入し、dist/ に静的サイトを出力
cd dist && python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開く（WebGL2 が必要）。`?lang=en` / `?lang=zh` で表示言語、`?touch=1` でタッチ向けの画面を試せます。

Windows 版：`cargo run --release --bin yyearth-win`（記録は `%APPDATA%\yyearth\saves`）。

Cloudflare への公開は YYMongolia と同じ（`bash build.sh && npx wrangler deploy`、または Pages でビルドコマンド `npm run build`・出力 `dist`）。

## ゲームの流れ

1. **地図（上空）**：カンブリア紀の地球を正距円筒図法で表示。クリック（タップ）した場所へカプセルが飛ぶ。
2. **時間旅行**：画面下の年表で時代を選ぶ。フォーチュニアン期〜第10期の10の期があり、選ぶと大陸がゆっくり動いて形と位置が変わる。「三葉虫の登場」「シンスク事変」「カルカリンジの巨大噴火」「SPICE事変」などの節目を越えると知らせが出る。
3. **潜る・降りる**：その場所の環境（陸・干潟・浅い海・大陸棚・外洋の深海）の断面に入る。水深に応じて暗くなり、深い海ではライトが要る。陸には植物がなく、微生物マットだけが岩を覆う。
4. **撮影**：生きものをある程度大きく・真ん中に・明るく写すと図鑑に収録される（小さすぎる・暗すぎる写真は収録されない）。逃げる魚、巣穴に引っ込む虫には、ゆっくり近づく。上空からは大陸の全体や大噴火を撮れる。
5. **宿題**：トキ先生から10の課題が出る。宿題のカードの「行く」を押すと、目的の生きものがいた時代と場所へカプセルが向かう。観察中は宿題の生きものが「!」の印で示される。

## 収録内容

- **大陸（9）**：ゴンドワナ・ローレンシア・バルティカ・アヴァロニア・シベリア・南中国・北中国・カザフの島々・タリム。キーフレームの間を補間して動く。海面が高かったカンブリア紀らしく、大陸の内側まで浅い海が入り込む。
- **化石の産地（10）**：フォーチュン岬（カンブリア紀の始まりの基準）、シベリアの礁、澄江、シリウス・パセット、エミュー湾、カルカリンジ火山地帯、バージェス、アヴァロニアの海、ミョウバン頁岩の海、ウィスコンシンの干潟。
- **生きもの（36）**：アノマロカリス、オパビニア、ハルキゲニア、ウィワクシア、マーレラ、ピカイア、ハイコウイクチス、カンブロラスター、タミシオカリス、ケリグマケラ、レドリキア、パラドキシデス、アグノストゥス、古杯類、ストロマトライト、ブルゲッソメデューサ、放散虫、ガラス海綿、クリマクティクニテスなど。すべて手続き的に描いた絵で、ひれを波打たせたり脚を動かしたりする。
- **現象（4）**：ゴンドワナ大陸・ローレンシア大陸（上空から全体を撮る）、カルカリンジの大噴火、植物のない大地。

時代・産地・大きさ・古地理はゲーム用に簡略化したおおよそのものです（Scotese・Torsvik などの古地理図や各化石産地の資料を参考にした）。

## 操作

| | マウス・キーボード | タッチ |
|---|---|---|
| 地図 | クリックで移動／WASD で移動・ドラッグや矢印キーで地図を動かす・ホイールで拡大縮小 | タップで移動・なぞる・2本指で拡大縮小 |
| 時代 | 年表をクリック、`,` `.` で期を移る | 年表をタップ・◀ ▶ |
| 潜る | Enter | 「潜る／降りる」 |
| 観察 | WASD・矢印・マウスを押した方へ進む／Shift で加速／ホイール・Q/E でズーム／L でライト／F で海底へ | 触れた方へ進む・＋－・ボタン |
| 撮影 | Space・右クリック | 撮影ボタン |
| 画面 | F1 宿題・F2 図鑑・F3 操作・Esc 浮上／閉じる・Ctrl＋＋/－ 文字の大きさ・F11 全画面 | 上のボタン |

進み具合は自動で記録される（ブラウザの IndexedDB。タイトル画面の「つづきから」）。操作画面からファイル（.yyesav）に書き出し・読み込みできる。

## 構成

| ファイル | 内容 |
|---|---|
| `src/earth.rs` | 大陸の形・位置・移動（キーフレーム）、地形の高さ、環境の判定、化石の産地、地球史の節目と期 |
| `src/life.rs` | 生きもの36種と現象4つのデータ（時代・すみか・産地・ふるまい・説明）、どこにいるかの判定 |
| `src/art.rs` | 生きものの絵（三角形で手続き的に描く） |
| `src/dive.rs` | 観察の場面：海底の地形、生きものの動き（泳ぐ・歩く・巣穴・漂う・逃げる）、カプセル、明るさとライト、写真の採点 |
| `src/mission.rs` | 宿題（トキ先生の課題） |
| `src/progress.rs` | 図鑑の収録状況・宿題・時と場所、その記録の読み書き |
| `src/game.rs` | 画面と操作：タイトル、地図、時間旅行、観察、図鑑、宿題、操作説明、写真、知らせ |
| `src/lang.rs` | 日本語・英語・中国語 |
| `src/gfx.rs`・`src/web.rs`・`src/platform.rs`・`web/` | ブラウザ版の描画・入力・記録（YYMongolia から流用） |
| `src/main.rs`・`src/win/*` | Windows 版（YYMongolia から流用） |
| `tools/make_icons.py` | アイコンを作る |

## テスト

```
cargo test --release --lib
```

大陸どうしが重ならないこと、産地がふさわしい環境にあること、すべての生きものに会いに行けること、記録の読み書き、場面での写真の採点、すべての画面の描画などを確かめる。
地図を画像に書き出して確かめるには `YY_DUMP=出力先 cargo test --release --lib dump_map -- --ignored`。
